# Wildrune 
Unity 2D platformer project with five data-driven levels, keyboard controls, optional touchscreen controls, sword and bow combat, checkpoints, a 5 heart health system and coins for heart recovery, and level-specific music.

## Open and run
For developing:
1. Open the project in Unity **6000.6.0f1**.
2. Press Play to test. In Settings, choose Keyboard or Touchscreen.
3. For mobile builds, install Android Build Support / iOS Build Support through Unity Hub and test on a real device.

To just play the game, go to the Releases tab and download the latest build. As of the latest update, there is only an official Windows build.

## Controls
- Keyboard: A/D or arrows to move, Space/W to jump, J/left-click for sword, K/right-click for bow.
- Touchscreen: floating joystick at lower-left; Jump at lower-right with Sword directly left and Bow directly above; MENU sits immediately left of the visible timer.
